나만의 앱으로 커스터마이징하기¶

🎯 이 장에서 배우는 것¶

  • 앱 제목, 색상, 과목 목록 등을 자신의 취향에 맞게 수정할 수 있다
  • AI에게 새로운 기능 추가를 요청하는 방법을 알 수 있다
  • 커스터마이징 후 재배포하여 변경 사항을 확인할 수 있다

📚 핵심 개념¶

개념: 커스터마이징 포인트¶

"커스터마이징은 마치 새 집에 입주한 뒤 벽지와 가구를 바꾸는 것과 같아요."

집의 구조(기둥, 배관)는 그대로 두고, 눈에 보이는 부분만 취향대로 바꾸면 완전히 다른 느낌의 공간이 되죠. 앱도 마찬가지입니다.

우리가 바꿀 수 있는 커스터마이징 포인트는 크게 세 가지입니다.

  • 텍스트: 앱 제목, 버튼 문구, 안내 메시지
  • 스타일: 배경 색상, 글자 크기, 테마 컬러
  • 데이터: 과목 목록, 선택지, 기본값

이런 부분은 코드에서 따옴표 안의 문자열이나 색상 코드로 되어 있어서, 값만 바꾸면 앱 전체 분위기가 달라집니다! 🎨

🔨 따라하기¶

Step 1: 제목과 과목 목록 바꾸기¶

AI Studio Build에서 코드를 열고, 아래와 같은 부분을 찾아 수정해보세요.

수정 전: 

st.title("📝 수강신청 앱")

subjects = ["국어", "영어", "수학", "과학"]

수정 후: 

st.title("🎵 동아리 신청 앱")  # 원하는 제목으로!

subjects = ["음악", "미술", "체육", "연극"]  # 원하는 항목으로!

포인트: 따옴표("...") 안의 글자만 바꾸면 됩니다. 따옴표 자체는 지우지 마세요!

Step 2: AI에게 새 기능 요청하기¶

직접 코드를 수정하는 것 외에, AI에게 말로 요청할 수도 있습니다.

AI Studio Build 채팅창에 이렇게 입력해보세요.

"신청 완료 시 축하 풍선 애니메이션을 추가해줘"

"배경색을 연한 파란색(#E8F4FD)으로 바꿔줘"

"신청자 이름을 입력받는 칸을 추가해줘"

AI가 코드를 수정해주면, 미리보기에서 결과를 바로 확인할 수 있습니다. 마음에 들지 않으면 "되돌려줘"라고 하면 돼요. 부담 없이 실험해보세요! 🧪

수정이 완료되면, 12장에서 배운 것처럼 Deploy 버튼을 눌러 재배포하세요. 몇 초 후 URL에 접속하면 변경 사항이 반영된 세상에 하나뿐인 나만의 앱을 만나볼 수 있습니다. 🎉

📝 전체 코드¶

import streamlit as st

# 🎨 여기를 수정하세요! - 커스터마이징 포인트
app_title = "🎵 동아리 신청 앱"        # 앱 제목
subjects = ["음악", "미술", "체육", "연극"]  # 선택 항목
theme_color = "#4CAF50"                # 테마 색상

st.title(app_title)

name = st.text_input("이름을 입력하세요")
choice = st.selectbox("희망 동아리를 선택하세요", subjects)

if st.button("신청하기"):
    if name:
        st.success(f"🎉 {name}님, {choice} 동아리 신청 완료!")
        st.balloons()
    else:
        st.warning("이름을 먼저 입력해주세요.")

⚠️ 주의할 점¶

  • 따옴표 짝 맞추기: "동아리 신청 앱" 처럼 따옴표는 반드시 열고 닫아야 합니다. 하나만 지우면 에러가 나요.
  • 쉼표 빠뜨리지 않기: 리스트 항목 사이에 쉼표(,)가 빠지면 오류가 발생합니다. ["음악", "미술"] ← 이 쉼표요!

✅ 점검하기¶

1. 앱 제목을 "출석 체크"로 바꾸려면 코드 어디를 수정하면 될까요?

정답 확인 `app_title = "출석 체크"` — 따옴표 안의 문자열만 바꾸면 됩니다.

2. AI에게 기능 추가를 요청했는데 결과가 마음에 안 들면 어떻게 하나요?

정답 확인 채팅창에 "되돌려줘"라고 말하면 이전 상태로 복원할 수 있습니다. 실험은 언제든 되돌릴 수 있으니 자유롭게 시도하세요!

3. 수정한 내용을 다른 사람도 볼 수 있게 하려면 마지막에 무엇을 해야 하나요?

정답 확인 Deploy(재배포) 버튼을 눌러야 합니다. 재배포해야 URL에 변경 사항이 반영됩니다.
