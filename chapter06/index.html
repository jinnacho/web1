Chapter 6: Firebase Realtime Database 설정하기¶

🎯 이 장에서 배우는 것¶

  • Firebase 콘솔에서 Realtime Database를 생성할 수 있다
  • 테스트 모드로 보안 규칙을 설정할 수 있다
  • 데이터베이스 URL의 역할을 이해할 수 있다

📚 핵심 개념¶

개념: Realtime Database¶

비유부터 시작할게요! 🏫

Realtime Database는 마치 교실 칠판에 붙인 공유 메모장과 같아요.

한 학생이 메모장에 이름을 적으면, 교실에 있는 모든 사람이 즉시 그 내용을 볼 수 있죠. 누군가 지우면 그것도 바로 반영됩니다.

정확한 정의: Firebase Realtime Database는 클라우드에 데이터를 저장하고, 연결된 모든 기기에 실시간으로 동기화해주는 데이터베이스입니다.

💡 우리 앱에서는 학생들의 상담 신청 데이터가 이 메모장에 저장됩니다!

🔨 따라하기¶

Step 1: Realtime Database 생성하기¶

  1. Firebase 콘솔에 접속합니다
  2. 이전 장에서 만든 프로젝트를 클릭합니다
  3. 왼쪽 메뉴에서 "빌드" → "Realtime Database" 를 클릭합니다
  4. "데이터베이스 만들기" 버튼을 클릭합니다
  5. 위치 선택: 싱가포르(asia-southeast1) 를 선택하고 "다음" 클릭
  6. 보안 규칙: "테스트 모드에서 시작" 을 선택하고 "사용 설정" 클릭

Step 2: 데이터베이스 URL 확인하기¶

생성이 완료되면 화면 상단에 URL이 표시됩니다.

https://your-project-name-default-rtdb.asia-southeast1.firebasedatabase.app/

이 URL이 바로 우리 앱이 데이터를 주고받을 데이터베이스 주소입니다. 📬

이 주소는 나중에 앱 코드에서 사용하니 기억해 두세요!

⚠️ 주의할 점¶

🔴 테스트 모드는 임시 설정입니다!

테스트 모드는 누구나 데이터를 읽고 쓸 수 있는 상태예요. 실습할 때는 편리하지만, 실제 서비스에서는 반드시 보안 규칙을 변경해야 합니다. Firebase가 30일 후 만료 경고를 보내주니, 그때 규칙을 수정하면 됩니다.

🟡 위치 선택은 변경 불가!

한번 선택한 데이터베이스 위치는 나중에 바꿀 수 없어요. 한국에서 사용한다면 싱가포르가 가장 가까운 선택지입니다.

✅ 점검하기¶

1. Realtime Database는 어떤 역할을 하나요?

정답 확인모든 사용자의 데이터를 클라우드에 저장하고, 연결된 기기에 실시간으로 동기화해주는 역할을 합니다.

2. 테스트 모드를 실제 서비스에서 그대로 쓰면 안 되는 이유는?

정답 확인테스트 모드는 누구나 데이터를 읽고 쓸 수 있어서, 보안에 취약하기 때문입니다.

3. 데이터베이스 URL은 어디에 사용되나요?

정답 확인앱 코드에서 데이터를 저장하거나 불러올 때, 어떤 데이터베이스에 접근할지 알려주는 주소로 사용됩니다.
