Node.js 설치하기¶

🎯 이 장에서 배우는 것¶

  • Node.js가 왜 필요한지 설명할 수 있다
  • Node.js LTS 버전을 설치할 수 있다
  • node -v 명령어로 설치를 확인할 수 있다

📚 핵심 개념¶

개념: Node.js¶

비유부터 시작할게요! 🔌

여러분이 만들 웹앱은 전자제품이라고 생각해보세요. 전자제품을 돌리려면 발전기(전기)가 필요하죠? Node.js는 바로 그 발전기 역할이에요.

정확한 정의: Node.js는 JavaScript를 컴퓨터에서 실행할 수 있게 해주는 프로그램입니다.

왜 필요할까요? 다음 장에서 설치할 Firebase 도구가 Node.js 위에서 작동해요. Node.js 없이는 Firebase 도구를 쓸 수 없습니다.

flowchart LR A["Node.js 🔌\n(발전기)"] --> B["Firebase 도구 ⚙️"] B --> C["우리의 웹앱 🚀"]

💡 LTS란? Long Term Support의 약자로, "오래 안정적으로 지원하는 버전"이라는 뜻이에요. 항상 LTS를 선택하세요!

🔨 따라하기¶

Step 1: Node.js 다운로드 & 설치¶

  1. 브라우저에서 https://nodejs.org 에 접속합니다
  2. 화면에 큰 초록색 버튼 두 개가 보여요 → 왼쪽 LTS 버전을 클릭합니다
  3. 다운로드된 설치 파일을 실행합니다
  4. 설치 화면에서 모두 "Next"만 누르면 됩니다 → 마지막에 "Finish" 클릭!

🍎 Mac 사용자: .pkg 파일이 다운로드되고, "계속"만 누르면 됩니다.

Step 2: 설치 확인하기¶

Windows: 키보드에서 Windows키 + R → cmd 입력 → 확인

Mac: Command + Space → 터미널 검색 → 실행

열린 화면에 아래 명령어를 입력하고 Enter!

node -v

실행 결과: 

v22.15.0

버전 번호가 뜨면 설치 성공입니다! 🎉 (숫자는 다를 수 있어요)

⚠️ 주의할 점¶

  1. 'node'은(는) 인식할 수 없는 명령입니다 라고 뜨나요? → 명령 프롬프트(터미널)를 완전히 닫고 새로 열어보세요. 설치 직후에는 이전 창이 Node.js를 인식하지 못할 수 있어요.
  2. 그래도 안 되면 컴퓨터를 재부팅 후 다시 시도해보세요.

✅ 점검하기¶

1. Node.js는 이 프로젝트에서 어떤 역할을 하나요?

정답 확인Firebase 도구를 실행하기 위한 기반(발전기) 역할을 합니다.

2. Node.js 설치 시 어떤 버전을 선택해야 하나요?

정답 확인LTS(Long Term Support) 버전을 선택합니다.

3. 설치 확인 명령어는 무엇인가요?

정답 확인node -v
