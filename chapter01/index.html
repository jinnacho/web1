우리가 만들 앱 미리보기¶

🎯 이 장에서 배우는 것¶

  • 완성된 방과후학교 신청 앱의 모습과 기능을 설명할 수 있다
  • 웹앱이 무엇인지 일상 속 예시를 들어 설명할 수 있다
  • 이 프로젝트에서 사용할 도구 5가지의 역할을 구분할 수 있다

📚 핵심 개념¶

개념: 우리가 만들 웹앱¶

우리가 4시간(14차시) 동안 만들 앱은 방과후학교 수업 신청 웹앱입니다.

두 가지 화면으로 구성돼요.

  • 🙋 학생용 화면 — 원하는 수업을 골라 신청하는 화면
  • 👩‍🏫 교사용 화면 — 누가 어떤 수업을 신청했는지 한눈에 관리하는 화면

웹앱이란?¶

"웹앱은 마치 카카오톡으로 링크를 공유하는 것과 같아요."

별도로 앱을 설치할 필요 없이, 링크만 클릭하면 바로 열리는 앱이 웹앱입니다. 크롬, 사파리 같은 브라우저에서 바로 동작하죠. 우리가 만들 신청 앱도 학생들에게 링크만 보내면 끝! 📱💻

사용할 도구 5가지¶

요리에 비유하면 이해가 쉬워요. 🍳

  • AI Studio Build — 🧑‍🍳 AI 요리사. 코드를 자동으로 만들어줌
  • Firebase — 🗄️ 냉장고. 신청 데이터를 저장하고 꺼내줌
  • Next.js — 🍽️ 그릇. 화면을 예쁘게 보여주는 틀
  • Node.js — 🔥 가스레인지. 코드가 실행되는 환경
  • VS Code — 🔪 도마와 칼. 코드를 편집하는 작업 공간

⚠️ 주의할 점¶

  • 지금은 도구를 설치하지 않아도 됩니다. 다음 차시부터 하나씩 세팅해요!
  • 코딩을 몰라도 괜찮아요. AI가 코드를 만들어주고, 우리는 조립하고 이해하는 역할입니다 😊

✅ 점검하기¶

1. 웹앱의 가장 큰 특징은 무엇인가요?

정답 확인앱 설치 없이 브라우저에서 링크만 클릭하면 바로 사용할 수 있다는 점입니다.

2. Firebase는 어떤 역할을 하나요?

정답 확인냉장고처럼 데이터를 저장하고 꺼내주는 역할을 합니다. 학생들의 신청 정보가 여기에 저장됩니다.

3. 우리가 만들 앱의 두 가지 화면은?

정답 확인학생이 수업을 신청하는 "학생용 화면"과, 신청 현황을 관리하는 "교사용 화면"입니다.
