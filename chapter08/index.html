Chapter 8: Firebase Hosting으로 앱 배포하기 🚀¶

🎯 이 장에서 배우는 것¶

  • firebase init 명령어로 호스팅 설정을 완료할 수 있다
  • firebase deploy 명령어로 앱을 인터넷에 배포할 수 있다
  • 배포된 URL로 접속하여 친구에게 공유할 수 있다

📚 핵심 개념¶

개념: 배포(Deploy)¶

"배포는 마치 내 방에서 만든 작품을 전시회에 내놓는 것과 같아요" 🎨

지금까지 우리 앱은 내 컴퓨터에서만 볼 수 있었어요. 배포란 이 파일들을 인터넷 서버에 올려서 누구나 URL로 접속할 수 있게 만드는 과정입니다.

Firebase Hosting이 바로 그 전시회장 역할을 해줍니다. 무료이고, 명령어 두 줄이면 끝!

🔨 따라하기¶

Step 1: firebase init으로 호스팅 설정하기¶

명령 프롬프트(터미널)에서 프로젝트 폴더로 이동한 뒤 실행하세요.

firebase init

화살표 키로 Hosting을 선택하고 스페이스바 → 엔터를 누르세요.

이어지는 질문에 아래처럼 답합니다:

  • What do you want to use as your public directory? → public 입력
  • Configure as a single-page app? → N 입력
  • Set up automatic builds with GitHub? → N 입력
  • File public/index.html already exists. Overwrite? → ⚠️ N 입력 (덮어쓰면 우리 앱이 사라져요!)

실행 결과: 

✔ Firebase initialization complete!

이 메시지가 보이면 설정 성공입니다! 👏

Step 2: firebase deploy로 배포하기¶

이제 진짜 배포입니다. 한 줄이면 돼요!

firebase deploy

실행 결과: 

✔ Deploy complete!

Hosting URL: https://내프로젝트명.web.app

🎉 이 URL이 바로 내 앱의 인터넷 주소입니다!

스마트폰 브라우저에서 이 URL을 열어보세요. 내가 만든 신청 화면이 그대로 보인다면 배포 성공입니다!

카카오톡으로 친구에게 링크를 보내서 접속해보라고 해보세요 📱

⚠️ 주의할 점¶

  • public/index.html 덮어쓰기 금지: init 과정에서 Overwrite 질문에 반드시 N을 선택하세요. Y를 누르면 기본 환영 페이지로 바뀌어 우리 코드가 날아갑니다.
  • 인터넷 연결 필수: deploy는 파일을 서버에 업로드하는 과정이므로 Wi-Fi나 데이터가 연결되어 있어야 합니다.

✅ 점검하기¶

1. 배포(deploy)란 무엇인가요?

정답 확인내 컴퓨터에 있는 파일을 인터넷 서버에 올려서 누구나 URL로 접속할 수 있게 만드는 과정입니다.

2. firebase init에서 public/index.html을 덮어쓰겠냐는 질문에 뭐라고 답해야 하나요?

정답 확인N (No)을 입력해야 합니다. Y를 누르면 우리가 만든 앱 코드가 사라집니다.

3. 배포 후 내 앱에 접속할 수 있는 URL 형식은?

정답 확인https://내프로젝트명.web.app 형식입니다.
