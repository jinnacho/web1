Chapter 4: Firebase CLI 설치하고 로그인하기¶

🎯 이 장에서 배우는 것¶

  • npm 명령어로 Firebase CLI를 설치할 수 있다
  • firebase login으로 Google 계정 인증을 완료할 수 있다

📚 핵심 개념¶

개념: CLI (Command Line Interface)¶

"CLI는 마치 문자 메시지로 컴퓨터에게 심부름을 시키는 것과 같아요."

마우스로 클릭하는 대신, 글자를 타이핑해서 컴퓨터에게 명령을 내리는 방식입니다. Firebase CLI를 설치하면, 터미널에서 글자 몇 줄만으로 우리 프로젝트를 Firebase 서버에 배포할 수 있게 됩니다. 🚀

🔨 따라하기¶

Step 1: Firebase CLI 설치하기¶

VS Code에서 터미널을 열고(Ctrl + `), 아래 명령어를 입력하세요.

명령어: 

npm install -g firebase-tools

💡 -g는 "global(전역)"의 약자예요. 어떤 폴더에서든 firebase 명령어를 쓸 수 있도록 컴퓨터 전체에 설치하라는 뜻입니다.

설치 중 여러 줄의 메시지가 쭉 올라갑니다. 당황하지 마세요! 정상입니다. 설치가 끝나면 아래 명령어로 확인해봅니다.

firebase --version

실행 결과 (예시): 

13.15.1

버전 숫자가 나오면 설치 성공입니다! 🎉

Step 2: Google 계정으로 로그인하기¶

이제 Firebase에 "나 이 컴퓨터의 주인이야!"라고 알려줄 차례입니다.

명령어: 

firebase login

진행 순서:

  1. 터미널에 Allow Firebase to collect CLI usage...? 라고 물어보면 → Y 입력 후 Enter
  2. 🌐 브라우저가 자동으로 열립니다 → Chapter 2에서 만든 Google 계정으로 로그인
  3. "Firebase CLI가 Google 계정에 액세스하도록 허용"에서 허용 클릭
  4. "Woohoo!" 또는 ✅ 성공 메시지가 브라우저에 나타남

터미널 결과: 

✔ Success! Logged in as yourname@gmail.com

이 메시지가 보이면 로그인 완료입니다! 👏

⚠️ 주의할 점¶

  • npm 명령어가 안 된다면? → Chapter 3의 Node.js 설치가 정상적으로 되었는지 확인하세요
  • 브라우저가 자동으로 안 열린다면? → 터미널에 표시된 URL을 직접 복사해서 브라우저에 붙여넣기 하세요

✅ 점검하기¶

1. Firebase CLI가 정상 설치되었는지 확인하는 명령어는?

정답 확인 `firebase --version` — 버전 번호가 출력되면 성공!

2. npm install -g에서 -g의 의미는?

정답 확인 global(전역) 설치. 특정 폴더가 아니라 컴퓨터 어디서든 해당 명령어를 사용할 수 있게 합니다.

3. firebase login 후 성공하면 터미널에 어떤 메시지가 나오나요?

정답 확인 `✔ Success! Logged in as 본인이메일@gmail.com`
