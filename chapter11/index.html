Chapter 11: CSV 다운로드 기능 추가하기¶

🎯 이 장에서 배우는 것¶

  • CSV 파일이 무엇이고 어떤 상황에서 유용한지 설명할 수 있다
  • 교사용 화면에 CSV 다운로드 버튼을 추가하고 동작을 확인할 수 있다
  • 다운로드된 CSV 파일을 엑셀에서 열어 데이터를 확인할 수 있다

📚 핵심 개념¶

개념: CSV (Comma-Separated Values)¶

비유로 시작 📋

CSV는 마치 줄노트에 쉼표로 칸을 나눠 쓴 명단과 같아요. 첫 줄에 "학번, 이름, 과목"이라고 제목을 쓰고, 그 아래로 한 줄에 한 명씩 "20301, 김민수, 수학"처럼 적는 거예요.

정확한 정의

CSV는 데이터를 쉼표(,)로 구분하여 저장하는 텍스트 파일 형식입니다. 확장자는 .csv이고, 엑셀이나 구글 스프레드시트에서 바로 열 수 있습니다.

예시로 확인

학번,이름,선택과목
20301,김민수,수학
20302,이서연,영어
20303,박지호,과학

이 텍스트 파일을 엑셀에서 열면 자동으로 표가 됩니다. 교사가 신청 명단을 인쇄하거나 정리할 때 아주 유용하죠!

🔨 따라하기¶

Step 1: AI에게 CSV 다운로드 기능 요청하기¶

Firebase AI Studio(또는 사용 중인 AI 도구)에 다음과 같은 프롬프트를 입력하세요.

프롬프트 예시: "admin.html에 CSV 다운로드 버튼을 추가해줘. 버튼을 누르면 Firestore의 신청 데이터(학번, 이름, 선택과목)를 CSV 파일로 다운로드하는 JavaScript 함수를 만들어줘. 한글이 깨지지 않도록 UTF-8 BOM을 포함해줘."

💡 포인트: "UTF-8 BOM 포함"이라고 꼭 언급하세요. 이걸 빠뜨리면 엑셀에서 한글이 깨집니다!

Step 2: 생성된 코드를 admin.html에 적용하기¶

AI가 생성해주는 코드의 핵심 구조는 아래와 같습니다. 기존 admin.html에 다운로드 버튼과 JavaScript 함수를 추가하세요.

버튼 추가 (HTML 부분):

<!-- 기존 신청 목록 위나 아래에 추가 -->
<button onclick="downloadCSV()">📥 CSV 다운로드</button>

다운로드 함수 (JavaScript 부분):

function downloadCSV() {
  // 1. Firestore에서 이미 불러온 신청 데이터 활용
  const rows = ['\uFEFF학번,이름,선택과목']; // UTF-8 BOM + 헤더

  // applications는 이미 화면에 표시 중인 신청 데이터 배열
  applications.forEach(app => {
    rows.push(`${app.studentId},${app.name},${app.subject}`);
  });

  // 2. CSV 텍스트를 파일로 변환
  const csvContent = rows.join('\n');
  const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });

  // 3. 다운로드 링크 생성 후 자동 클릭
  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = '신청명단.csv';
  link.click();
}

⚡ \uFEFF가 바로 UTF-8 BOM입니다. 이 보이지 않는 문자 덕분에 엑셀이 "아, 이건 UTF-8이구나!" 하고 한글을 올바르게 표시합니다.

Step 3: 다운로드 테스트하기¶

  1. admin.html을 브라우저에서 열고 신청 목록이 표시되는지 확인
  2. 📥 CSV 다운로드 버튼 클릭
  3. 신청명단.csv 파일이 다운로드되면 엑셀에서 열기
✅ 기대 결과: 엑셀에 학번, 이름, 선택과목이 깔끔한 표로 표시됨

📝 전체 코드¶

<!-- admin.html에 추가할 부분 -->

<!-- 버튼 (신청 목록 영역 근처에 배치) -->
<button onclick="downloadCSV()">📥 CSV 다운로드</button>

<script>
// applications: Firestore에서 불러온 신청 데이터 배열
// (기존 코드에서 이미 선언되어 있다고 가정)

function downloadCSV() {
  if (!applications || applications.length === 0) {
    alert('다운로드할 데이터가 없습니다.');
    return;
  }

  // 헤더 + BOM
  const rows = ['\uFEFF학번,이름,선택과목'];

  // 데이터 행 추가
  applications.forEach(app => {
    rows.push(`${app.studentId},${app.name},${app.subject}`);
  });

  // Blob 생성 및 다운로드
  const csvContent = rows.join('\n');
  const blob = new Blob([csvContent], { type: 'text/csv;charset=utf-8;' });
  const link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = '신청명단.csv';
  link.click();
}
</script>

⚠️ 주의할 점¶

  1. 한글 깨짐 방지: \uFEFF(UTF-8 BOM)를 CSV 맨 앞에 반드시 넣으세요. 빠뜨리면 엑셀에서 한글이 ê¹€ë¯¼ì??? 처럼 깨져 보입니다.

  2. 데이터에 쉼표가 포함된 경우: 만약 데이터 값 안에 쉼표가 있으면(예: "수학, 영어") 칸이 잘못 나뉩니다. 이런 경우 값을 큰따옴표로 감싸야 합니다. 현재 학번·이름·과목명에는 쉼표가 없으므로 괜찮지만, 나중에 데이터가 복잡해지면 기억해두세요!

✅ 점검하기¶

1. CSV 파일에서 쉼표의 역할은 무엇인가요?

정답 확인 쉼표는 각 데이터 항목(열)을 구분하는 역할을 합니다. 엑셀에서 열면 쉼표를 기준으로 각각 다른 셀에 데이터가 배치됩니다.

2. \uFEFF를 넣지 않으면 어떤 문제가 생기나요?

정답 확인 엑셀에서 CSV 파일을 열 때 한글이 깨져서 알아볼 수 없는 문자로 표시됩니다. \uFEFF(UTF-8 BOM)는 엑셀에게 "이 파일은 UTF-8 인코딩이야"라고 알려주는 신호입니다.

3. 다운로드 버튼을 눌렀는데 "다운로드할 데이터가 없습니다"라고 뜨면 어떻게 해야 하나요?

정답 확인 Firestore에서 신청 데이터를 먼저 불러와야 합니다. 신청 목록이 화면에 표시된 상태에서 다운로드 버튼을 눌러야 정상 동작합니다.
