AI Studio Build로 학생용 앱 코드 생성하기¶

🎯 이 장에서 배우는 것¶

  • Google AI Studio Build에서 프롬프트로 웹앱 코드를 생성할 수 있다
  • 생성된 코드를 내 컴퓨터에 index.html 파일로 저장할 수 있다
  • AI가 만든 코드의 기본 구조(HTML, CSS, JavaScript)를 이해할 수 있다

📚 핵심 개념¶

개념: AI Studio Build¶

비유로 시작 ☕

"AI Studio Build는 마치 인테리어 전문가와 같아요. 우리가 '밝은 느낌의 카페를 만들어줘'라고 말하면, 전문가가 설계도부터 가구 배치까지 완성해주죠. AI Studio Build도 '이런 앱을 만들어줘'라고 말하면 코드를 통째로 만들어줍니다."

정확한 정의

Google AI Studio Build는 자연어(우리가 쓰는 말)로 원하는 웹앱을 설명하면, 바로 동작하는 HTML/CSS/JavaScript 코드를 생성해주는 AI 도구입니다.

AI가 만드는 코드의 3요소

graph LR A["🦴 HTML<br/>뼈대 · 구조"] --> D["완성된 웹앱"] B["👗 CSS<br/>옷 · 디자인"] --> D C["🧠 JavaScript<br/>두뇌 · 동작"] --> D
  • HTML — 화면에 무엇이 보이는지 (입력칸, 버튼, 글자)
  • CSS — 어떻게 보이는지 (색상, 크기, 배치)
  • JavaScript — 어떻게 동작하는지 (버튼 클릭 시 반응)

🔨 따라하기¶

Step 1: AI Studio Build 접속하기¶

  1. 브라우저에서 aistudio.google.com 에 접속합니다
  2. Google 계정으로 로그인합니다
  3. 왼쪽 메뉴 또는 상단에서 "Build" 를 클릭합니다
  4. 프롬프트 입력창이 나타나면 준비 완료! 🎉

💡 팁: Build 메뉴가 보이지 않으면 화면 상단의 탭을 확인해보세요. "Build with Gemini" 또는 유사한 이름일 수 있습니다.

Step 2: 프롬프트 입력하여 코드 생성하기¶

아래 프롬프트를 입력창에 그대로 복사해서 붙여넣고 전송하세요.

프롬프트:

수강신청 학생용 화면을 만들어줘.

요구사항:
- 상단에 "수강신청 시스템"이라는 제목
- 학번 입력칸, 이름 입력칸
- 과목 선택: 국어, 영어, 수학, 한국사, 과탐 (체크박스로 복수 선택 가능)
- "신청하기" 버튼
- 버튼을 누르면 "신청이 완료되었습니다"라는 알림 표시
- 디자인은 깔끔하고 모바일에서도 잘 보이게
- 한국어로 표시

전송 버튼을 누르면 AI가 코드를 생성하기 시작합니다. 미리보기 화면에서 학생용 신청 화면이 바로 나타나는 것을 확인하세요! 🖥️

🔑 좋은 프롬프트의 비결: "수강신청 만들어줘"처럼 막연하게 쓰지 않고, 어떤 입력칸이 필요한지, 과목은 무엇인지, 버튼 동작은 어떤지 구체적으로 적으면 원하는 결과를 얻을 수 있습니다.

Step 3: 코드를 내 컴퓨터에 저장하기¶

  1. AI가 생성한 코드 영역의 복사 버튼(📋)을 클릭합니다
  2. 내 컴퓨터에서 메모장(Windows) 또는 텍스트 편집기(Mac)를 엽니다
  3. 복사한 코드를 붙여넣기(Ctrl+V) 합니다
  4. 다른 이름으로 저장을 선택합니다
  5. 📁 저장 위치: 바탕화면에 만든 sugang 폴더 (또는 원하는 프로젝트 폴더)
  6. 📄 파일 이름: index.html
  7. ⚠️ 파일 형식: "모든 파일" 로 변경 (.txt가 아닌 .html로 저장되어야 합니다)
  8. 저장한 index.html 파일을 더블클릭하면 브라우저에서 앱이 열립니다! 🎊

📝 전체 코드¶

AI가 생성하는 코드는 매번 조금씩 다를 수 있지만, 핵심 구조는 아래와 같습니다. 참고용으로 확인해보세요.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>수강신청 시스템</title>
  <style>
    /* 👗 CSS: 디자인 담당 */
    body { font-family: sans-serif; max-width: 480px; margin: 40px auto; padding: 20px; }
    h1 { text-align: center; color: #2c3e50; }
    input { width: 100%; padding: 10px; margin: 8px 0; box-sizing: border-box; border: 1px solid #ccc; border-radius: 6px; }
    .subjects label { display: block; padding: 6px 0; font-size: 16px; }
    button { width: 100%; padding: 12px; margin-top: 16px; background: #3498db; color: white; border: none; border-radius: 6px; font-size: 16px; cursor: pointer; }
    button:hover { background: #2980b9; }
  </style>
</head>
<body>
  <!-- 🦴 HTML: 구조 담당 -->
  <h1>📚 수강신청 시스템</h1>

  <input type="text" id="studentId" placeholder="학번을 입력하세요">
  <input type="text" id="studentName" placeholder="이름을 입력하세요">

  <h3>과목 선택</h3>
  <div class="subjects">
    <label><input type="checkbox" value="국어"> 국어</label>
    <label><input type="checkbox" value="영어"> 영어</label>
    <label><input type="checkbox" value="수학"> 수학</label>
    <label><input type="checkbox" value="한국사"> 한국사</label>
    <label><input type="checkbox" value="과탐"> 과탐</label>
  </div>

  <button onclick="submitForm()">신청하기</button>

  <script>
    // 🧠 JavaScript: 동작 담당
    function submitForm() {
      const id = document.getElementById('studentId').value;
      const name = document.getElementById('studentName').value;
      if (!id || !name) {
        alert('학번과 이름을 입력해주세요!');
        return;
      }
      alert(name + '님, 신청이 완료되었습니다!');
    }
  </script>
</body>
</html>

실행 결과: 브라우저에서 학번·이름 입력칸, 과목 체크박스 5개, 신청하기 버튼이 깔끔하게 표시됩니다. 버튼 클릭 시 알림창이 뜹니다.

⚠️ 주의할 점¶

  1. 파일 확장자 확인: 저장할 때 index.html.txt가 되지 않도록 파일 형식을 "모든 파일" 로 꼭 변경하세요. 확장자가 .html이어야 브라우저에서 열립니다.
  2. AI 결과가 다를 수 있어요: AI는 같은 프롬프트에도 매번 조금씩 다른 코드를 생성합니다. 미리보기에서 원하는 모습이 나왔다면 그것을 저장하면 됩니다. 마음에 안 들면 다시 요청해도 괜찮아요! 🔄

✅ 점검하기¶

1. AI Studio Build에서 좋은 결과를 얻으려면 프롬프트를 어떻게 작성해야 할까요?

정답 확인 "앱 만들어줘"처럼 막연하게 쓰지 않고, **필요한 입력칸, 선택할 항목, 버튼 동작** 등을 구체적으로 적어야 합니다. 구체적일수록 원하는 결과에 가까운 코드가 생성됩니다.

2. HTML, CSS, JavaScript의 역할을 각각 한 단어로 말해보세요.

정답 확인 - **HTML** → 구조(뼈대) - **CSS** → 디자인(옷) - **JavaScript** → 동작(두뇌)

3. 생성된 코드를 저장할 때 파일 이름은 무엇으로 해야 하나요?

정답 확인 **index.html** 로 저장합니다. 확장자가 반드시 `.html`이어야 브라우저에서 웹페이지로 열립니다.
