Chapter 3: Firebase 프로젝트 만들기 🔥¶

🎯 이 장에서 배우는 것¶

  • Firebase가 어떤 역할을 하는지 이해할 수 있다
  • Firebase 콘솔에서 새 프로젝트를 생성할 수 있다
  • 웹 앱을 등록하고 firebaseConfig 정보를 확인할 수 있다

📚 핵심 개념¶

개념: Firebase¶

"Firebase는 마치 렌탈 창고 + 배달 서비스와 같아요."

우리가 만든 앱의 데이터를 저장해주고(창고), 완성된 앱을 인터넷에 올려서 누구나 접속할 수 있게 해주는(배달) Google의 만능 서버 서비스입니다.

직접 서버 컴퓨터를 사지 않아도, Firebase가 모든 걸 대신해줍니다. 무료 요금제로도 우리 프로젝트에 충분합니다! 😊

🔨 따라하기¶

Step 1: Firebase 프로젝트 생성¶

  1. Firebase 콘솔 에 접속합니다
  2. Google 계정으로 로그인합니다
  3. "프로젝트 추가" 버튼을 클릭합니다
  4. 프로젝트 이름에 my-first-app 을 입력합니다
  5. Google 애널리틱스는 "사용 안함" 으로 끄고 "프로젝트 만들기" 클릭!

💡 프로젝트 이름은 자유롭게 정해도 괜찮아요. 영문, 숫자, 하이픈만 사용하세요.

30초 정도 기다리면 "새 프로젝트가 준비되었습니다" 메시지가 나타납니다. "계속" 을 누르세요!

Step 2: 웹 앱 등록하기¶

  1. 프로젝트 대시보드에서 웹 아이콘 </> 을 클릭합니다
  2. 앱 닉네임에 my-web-app 을 입력합니다
  3. "Firebase 호스팅 설정" 체크박스는 지금은 체크하지 않습니다
  4. "앱 등록" 을 클릭합니다

그러면 아래와 같은 firebaseConfig 코드가 나타납니다:

// 이 정보가 앱과 Firebase를 연결하는 '열쇠'입니다 🔑
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "my-first-app.firebaseapp.com",
  projectId: "my-first-app",
  storageBucket: "my-first-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};

⚡ 지금 이 코드를 복사할 필요는 없습니다. 나중에 언제든 프로젝트 설정에서 다시 확인할 수 있어요. "콘솔로 이동" 을 눌러주세요.

⚠️ 주의할 점¶

  • firebaseConfig 값은 사람마다 다릅니다. 교재의 예시를 그대로 복사하면 안 되고, 반드시 본인 프로젝트의 값을 사용해야 해요
  • Google 계정이 없다면 먼저 계정을 만들어주세요

✅ 점검하기¶

1. Firebase는 우리 프로젝트에서 어떤 역할을 하나요?

정답 확인데이터를 저장하고, 완성된 앱을 인터넷에 배포해주는 서버 역할을 합니다.

2. firebaseConfig는 왜 중요한가요?

정답 확인우리가 만든 앱과 Firebase 서버를 연결해주는 '열쇠' 역할을 하기 때문입니다.

3. 프로젝트 대시보드 화면이 보이나요?

정답 확인대시보드에 프로젝트 이름과 함께 Firestore, Authentication 등의 메뉴가 보이면 성공입니다! 🎉
