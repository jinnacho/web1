Chapter 7: 앱과 Firebase 연동하기¶

🎯 이 장에서 배우는 것¶

  • firebaseConfig 정보를 앱 코드에 정확히 삽입할 수 있다
  • 신청 버튼을 눌러 Firebase에 데이터가 저장되는 흐름을 이해할 수 있다
  • Firebase 콘솔에서 저장된 데이터를 실시간으로 확인할 수 있다

📚 핵심 개념¶

개념: Firebase 연동¶

비유로 시작 🔌

지금까지 우리는 "앱(전자제품)"과 "Firebase(콘센트)"를 각각 준비했어요. 이번 장에서는 플러그를 꽂는 작업을 합니다. 플러그(firebaseConfig)를 콘센트에 정확히 꽂아야 전기(데이터)가 흐르겠죠?

정확한 정의

Firebase 연동이란, Chapter 3에서 복사해둔 firebaseConfig 정보(프로젝트 고유 주소)를 앱 코드에 삽입하여 앱과 Firebase 서버가 서로 통신할 수 있게 만드는 과정입니다.

데이터 흐름 확인

flowchart LR A["👩‍💻 학생이\n이름/학번 입력"] --> B["📱 신청 버튼\n클릭"] B --> C["🔌 firebaseConfig로\nFirebase에 연결"] C --> D["☁️ Realtime Database에\n데이터 저장"] D --> E["✅ Firebase 콘솔에서\n확인"]

버튼을 누르면 앱이 firebaseConfig 정보를 이용해 Firebase 서버를 찾아가고, 입력한 데이터를 저장합니다. 이 모든 과정이 1초도 안 되어 일어나요!

🔨 따라하기¶

Step 1: firebaseConfig 붙여넣기¶

Chapter 3에서 Firebase 프로젝트를 만들 때 복사해둔 설정 정보가 있죠? 이제 그걸 코드에 넣을 차례입니다.

index.html 파일을 열고, 아래와 같은 부분을 찾으세요:

// 🔽 여기에 본인의 firebaseConfig를 붙여넣으세요
const firebaseConfig = {
  apiKey: "여기에-본인-키",
  authDomain: "여기에-본인-도메인",
  databaseURL: "https://여기에-본인-주소.firebaseio.com",
  projectId: "여기에-본인-프로젝트ID",
  storageBucket: "여기에-본인-버킷",
  messagingSenderId: "여기에-본인-ID",
  appId: "여기에-본인-앱ID"
};

"여기에-..." 부분을 Chapter 3에서 복사한 본인의 실제 값으로 교체하세요.

💡 Config를 못 찾겠다면? Firebase 콘솔 → 프로젝트 설정(⚙️) → 일반 → 내 앱 → SDK 설정에서 다시 복사할 수 있어요.

Step 2: 브라우저에서 앱 실행하고 데이터 입력하기¶

  1. 수정한 index.html 파일을 더블클릭하여 브라우저에서 엽니다
  2. 화면에서 다음을 입력하세요:
  3. 학번: 20250101
  4. 이름: 홍길동
  5. 과목: 원하는 과목 선택
  6. 신청 버튼을 클릭! 🖱️

"신청이 완료되었습니다" 같은 메시지가 뜨면 일단 성공 신호입니다.

Step 3: Firebase 콘솔에서 데이터 확인하기¶

이제 진짜 저장되었는지 눈으로 확인해볼까요? 👀

  1. Firebase 콘솔에 접속
  2. 본인의 프로젝트 클릭
  3. 왼쪽 메뉴에서 Realtime Database 클릭
  4. 화면에 방금 입력한 홍길동, 20250101 데이터가 보이면 🎉 연동 성공!
my-project-default-rtdb
  └── requests
        └── -NxAbC123dEf
              ├── name: "홍길동"
              ├── studentId: "20250101"
              └── subject: "수학"

위처럼 트리 구조로 데이터가 표시됩니다. -NxAbC123dEf 같은 건 Firebase가 자동 생성한 고유 ID예요.

⚠️ 주의할 점¶

  • databaseURL을 빠뜨리지 마세요! firebaseConfig 항목 중 databaseURL이 없으면 데이터 저장이 아예 안 됩니다. Firebase 콘솔의 Realtime Database 탭 상단에서 URL을 확인할 수 있어요.
  • 브라우저 개발자 도구(F12)를 활용하세요. 신청 버튼을 눌렀는데 아무 반응이 없다면, F12 → Console 탭에서 빨간 에러 메시지를 확인해보세요. 대부분 config 오타가 원인입니다.

✅ 점검하기¶

1. firebaseConfig의 역할은 무엇인가요?

정답 확인 앱이 어떤 Firebase 프로젝트에 연결해야 하는지 알려주는 고유 주소 정보입니다. 이 정보가 있어야 앱이 올바른 데이터베이스를 찾아갈 수 있습니다.

2. 신청 버튼을 눌렀는데 Firebase에 데이터가 안 보입니다. 가장 먼저 확인할 것은?

정답 확인 ① firebaseConfig 값이 정확히 붙여넣어졌는지 확인 (특히 databaseURL) ② 브라우저 F12 → Console 탭에서 에러 메시지 확인 ③ Realtime Database 규칙이 읽기/쓰기 허용으로 설정되어 있는지 확인

3. Firebase 콘솔에서 저장된 데이터는 어디서 확인하나요?

정답 확인 Firebase 콘솔 → 본인 프로젝트 → 왼쪽 메뉴의 "Realtime Database" 탭에서 확인할 수 있습니다.
