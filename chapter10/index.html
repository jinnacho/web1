신청 데이터 수정·삭제 기능 구현하기¶

🎯 이 장에서 배우는 것¶

  • Firebase에서 데이터가 실시간 반영되는 것을 확인할 수 있다

📚 핵심 개념¶

개념: 데이터 수정과 삭제 (Update & Delete)¶

지난 시간에 우리는 교사용 관리 화면에서 데이터를 읽어오는(Read) 기능을 만들었어요. 이번에는 수정(Update)과 삭제(Delete)를 추가합니다.

🎯 비유: 출석부를 생각해 보세요. 학생 이름을 잘못 적었으면 지우고 다시 쓰고(수정), 전학 간 학생은 줄 자체를 지우는(삭제) 것과 같아요.

Firebase에서 사용하는 핵심 명령어는 딱 두 가지입니다.

  • update() — 특정 데이터의 값을 변경할 때
  • remove() — 특정 데이터를 완전히 삭제할 때

두 명령 모두 데이터의 고유 경로(key)를 알아야 해요. 9장에서 데이터를 읽어올 때 각 신청 항목마다 고유 key가 있었던 것, 기억나시죠? 바로 그 key를 활용합니다.

🔨 따라하기¶

Step 1: AI에게 수정·삭제 기능 요청하기¶

Google AI Studio의 Build with Gemini 채팅창에 아래 프롬프트를 입력하세요.

기존 admin.html의 신청 목록 테이블에 다음 기능을 추가해줘.

1. 각 행에 "수정" 버튼과 "삭제" 버튼을 추가
2. "수정" 버튼 클릭 시:
   - 해당 행의 텍스트가 입력 필드로 바뀜
   - "수정" 버튼이 "저장" 버튼으로 변경
   - "저장" 클릭 시 Firebase Realtime Database의 해당 데이터를 update()로 수정
3. "삭제" 버튼 클릭 시:
   - "정말 삭제하시겠습니까?" 확인 대화상자 표시
   - 확인 시 Firebase Realtime Database에서 remove()로 삭제
4. 수정·삭제 후 목록이 실시간으로 자동 갱신되도록 해줘

AI가 생성한 코드를 확인하고, 기존 admin.html에 반영합니다.

Step 2: 핵심 코드 이해하기¶

AI가 생성한 코드 중 수정과 삭제의 핵심 부분을 살펴볼게요.

삭제 기능 코드:

// 삭제 버튼 클릭 시
function deleteEntry(key) {
  if (confirm("정말 삭제하시겠습니까?")) {
    const entryRef = ref(database, 'applications/' + key);
    remove(entryRef)
      .then(() => console.log("삭제 완료!"))
      .catch((error) => console.error("삭제 실패:", error));
  }
}

수정(저장) 기능 코드:

// 저장 버튼 클릭 시
function saveEntry(key) {
  const newName = document.getElementById('edit-name-' + key).value;
  const newClass = document.getElementById('edit-class-' + key).value;

  const entryRef = ref(database, 'applications/' + key);
  update(entryRef, {
    name: newName,
    classNum: newClass
  })
    .then(() => console.log("수정 완료!"))
    .catch((error) => console.error("수정 실패:", error));
}

💡 포인트: 'applications/' + key가 바로 해당 학생 데이터의 고유 경로예요. 이 경로를 정확히 지정해야 원하는 데이터만 수정·삭제됩니다.

실행 결과:

1. 삭제 버튼 클릭 → 확인 대화상자 → "확인" → 해당 행 즉시 사라짐
2. 수정 버튼 클릭 → 텍스트가 입력 필드로 변환 → 값 수정 후 저장 → 즉시 반영
3. Firebase 콘솔에서도 데이터가 실시간으로 변경/삭제된 것을 확인!

📝 동작 흐름 정리¶

flowchart LR A[교사가 버튼 클릭] --> B{어떤 버튼?} B -->|수정| C[입력 필드로 전환] C --> D[저장 클릭] D --> E["update() 실행"] B -->|삭제| F[확인 대화상자] F -->|확인| G["remove() 실행"] E --> H[Firebase 실시간 반영] G --> H H --> I[화면 자동 갱신]

⚠️ 주의할 점¶

  • 삭제는 되돌릴 수 없어요! remove()로 삭제한 데이터는 복구할 수 없으므로 반드시 confirm() 확인 대화상자를 넣으세요.
  • key 값을 정확히 전달해야 해요. key가 잘못되면 엉뚱한 데이터가 수정·삭제될 수 있습니다. 9장에서 목록을 그릴 때 각 항목의 key를 버튼에 연결하는 부분을 꼭 확인하세요.

✅ 점검하기¶

1. Firebase에서 특정 데이터를 삭제할 때 사용하는 함수는?

정답 확인 remove() 함수를 사용합니다. 삭제할 데이터의 경로(ref)를 지정하여 호출합니다.

2. 수정 기능에서 update()와 set()의 차이는 무엇일까요?

정답 확인 update()는 지정한 필드만 변경하고 나머지는 그대로 유지합니다. set()은 해당 경로의 데이터를 통째로 덮어쓰므로, 지정하지 않은 필드는 삭제될 수 있습니다. 부분 수정에는 update()가 안전합니다.

3. 삭제 버튼에 confirm() 대화상자를 넣는 이유는?

정답 확인 삭제된 데이터는 복구할 수 없기 때문에, 실수로 삭제하는 것을 방지하기 위해 사용자에게 한 번 더 확인을 받는 것입니다.
