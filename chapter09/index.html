교사용 관리 페이지 코드 생성하기¶

🎯 이 장에서 배우는 것¶

  • AI Studio Build로 교사용 관리 화면 코드를 생성할 수 있다
  • 생성된 코드를 admin.html로 저장하고 학생용 화면과 연결할 수 있다
  • 관리 페이지가 Firebase 데이터를 읽어와 표로 보여주는 흐름을 설명할 수 있다

📚 핵심 개념¶

개념: 교사용 관리 페이지¶

학생용 화면이 "신청서를 제출하는 창구" 라면, 교사용 관리 페이지는 "접수된 신청서를 모아보는 사무실 책상" 과 같아요. 📋

학생은 데이터를 쓰기만 하지만, 교사는 데이터를 읽고, 수정하고, 삭제할 수 있어야 합니다. 이 차이를 한 장의 흐름도로 정리하면 이렇습니다.

flowchart LR A["학생 화면\n(index.html)"] -->|신청 데이터 저장| B["Firebase\nFirestore"] B -->|데이터 불러오기| C["교사 관리 화면\n(admin.html)"] C -->|수정 · 삭제| B

즉, 이번 장에서는 Firebase에 저장된 신청 목록을 표로 보여주고 관리하는 페이지를 AI에게 요청해서 만듭니다.

🔨 따라하기¶

Step 1: AI에게 관리 페이지 코드 요청하기¶

AI Studio Build(또는 사용 중인 AI 코드 생성 도구)에 아래 프롬프트를 입력하세요.

프롬프트 예시 💬

"Firebase Firestore의 applications 컬렉션에서 데이터를 읽어와 HTML 표(table)로 보여주는 관리 페이지를 만들어줘. 각 행마다 수정 버튼과 삭제 버튼이 있어야 해. 파일 이름은 admin.html이고, 이전에 만든 index.html과 같은 Firebase 프로젝트 설정을 사용해."

생성된 코드를 복사해서 프로젝트 폴더에 admin.html로 저장합니다.

Step 2: 두 페이지를 연결하기¶

학생용 index.html 하단에 아래 한 줄을 추가하세요.

<!-- index.html 하단에 추가 -->
<a href="admin.html">🔑 교사용 관리 페이지로 이동</a>

반대로 admin.html에도 돌아가는 링크를 넣어줍니다.

<!-- admin.html 상단에 추가 -->
<a href="index.html">⬅ 학생 신청 페이지로 돌아가기</a>

실행 결과: 브라우저에서 index.html을 열면 하단 링크를 클릭해 관리 페이지로 이동할 수 있고, 관리 페이지에는 Firestore에 저장된 신청 내역이 표 형태로 표시됩니다. 🎉

📝 전체 코드¶

admin.html의 핵심 구조만 발췌합니다. Firebase 설정 부분은 index.html과 동일하므로 그대로 복사하세요.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>교사용 관리 페이지</title>
</head>
<body>
  <h1>📋 신청 내역 관리</h1>
  <a href="index.html">⬅ 학생 신청 페이지로 돌아가기</a>
  <table id="appTable" border="1">
    <thead>
      <tr><th>이름</th><th>내용</th><th>관리</th></tr>
    </thead>
    <tbody></tbody>
  </table>

  <!-- Firebase SDK & 설정 (index.html과 동일) -->
  <script src="firebase-config.js"></script>
  <script>
    const db = firebase.firestore();

    // 데이터 불러오기
    db.collection("applications").get().then(snapshot => {
      const tbody = document.querySelector("#appTable tbody");
      snapshot.forEach(doc => {
        const d = doc.data();
        const tr = document.createElement("tr");
        tr.innerHTML = `
          <td>${d.name}</td>
          <td>${d.content}</td>
          <td>
            <button onclick="deleteDoc('${doc.id}')">삭제</button>
          </td>`;
        tbody.appendChild(tr);
      });
    });

    // 삭제 기능
    function deleteDoc(id) {
      if (confirm("정말 삭제할까요?")) {
        db.collection("applications").doc(id).delete()
          .then(() => location.reload());
      }
    }
  </script>
</body>
</html>

⚠️ 주의할 점¶

  • Firebase 설정 일치: admin.html의 Firebase 설정이 index.html과 똑같은 프로젝트를 가리켜야 데이터가 보입니다. 다르면 빈 표만 나와요!
  • 실제 서비스라면 인증 필수: 지금은 학습용이라 누구나 접근 가능하지만, 실제로는 교사만 관리 페이지에 들어올 수 있도록 로그인 기능을 추가해야 합니다. 🔐

✅ 점검하기¶

1. 학생용 화면과 교사용 화면의 가장 큰 역할 차이는 무엇인가요?

정답 확인학생용 화면은 데이터를 **쓰기(생성)** 하고, 교사용 화면은 데이터를 **읽기·수정·삭제** 합니다.

2. admin.html이 Firestore 데이터를 표로 보여주려면 어떤 메서드를 사용하나요?

정답 확인db.collection("applications").get()으로 전체 문서를 가져온 뒤, 각 문서를 테이블 행으로 추가합니다.

3. 두 페이지를 연결하기 위해 HTML에서 사용한 태그는?

정답 확인<a href="파일명"> 태그(앵커 태그)를 사용하여 페이지 간 링크를 만듭니다.
